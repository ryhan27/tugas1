# Tugas 1 Pengenalan Dart

Tugas 1 pengenalan Dart, saya bikin program kasir buat jasa laundry.

* Tipe data utama (String, int, double, bool) saya pake buat nyatet nama pelanggan, berat timbangan, dan lain-lain.
* String interpolation (nyisipin variabel langsung ke dalam kalimat cuma pake simbol $).
* Nullable (?) digabungin sama (??) buat antisipasi kalau pelanggannya gak ngasih request mau pakai parfum apa.
* late, final, dan const dipake buat ngamanin variabel biar nilainya tetep paten (contohnya buat nyimpen merk laundry atau kode struk).
* Operasi standar buat ngaliin harga per kilo sama nambahin biaya antar.
* List buat bikin deretan paketan cuci (nggak lupa nyicipin fungsi .add buat nambahin data baru).
* Set dipake buat nyimpen macam-macam bahan kain biar daftarnya unik dan nggak ada yang dobel.
* Map buat ngebungkus semua detail transaksi ke dalem satu nota (tipe value-nya di-set dynamic biar teks sama angka bisa kumpul di satu tempat).
